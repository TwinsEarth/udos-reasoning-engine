# v7.3.9 高斯泼溅 + Real-to-Sim / Sim-to-Real（CPU 原型）

## 1. 对标概念
- **Gaussian Splatting（高斯泼溅）**：用大量带尺度/透明度/颜色的三维高斯
  堆叠出场景，可微、渲染快；完整 3DGS 难表达动态、训练依赖 GPU。Atlas 支持
  但已不再强制依赖它。
- **Real-to-Sim**：把真实环境转成可训练/测试的仿真环境（深度噪声、位姿抖动
  代理真实采集），压缩重建成本。
- **Sim-to-Real**：把仿真策略迁到“真实”世界；核心难题是**模型失配**。

## 2. 实现（`udos7/spatial/`）
- `splat.py`：3DGS-lite——轴对齐三维高斯，针孔一阶 footprint，前到后
  alpha 合成深度/颜色；从 v7.3.8 的 TSDF 占据点初始化，Adam 拟合颜色+深度
  （150 高斯、40 步、36×28）。
- `transfer.py`：
  - 带噪观测（深度高斯噪声+丢点、相机位姿抖动）→ TSDF 重建 → 6-连通聚类
    抽取障碍球，按机器人 z=0 平面取截圆（体素尺度的膨胀在合成真值上标定扣除）；
  - 重建结果直接生成 v7.3.7 具身混合控制器可用的过门任务；
  - Sim-to-Real：规划器只持有**有偏障碍估计**，在固定 seed 扰动的“真实代理”
    世界闭环执行（规划/执行环境分离），对比朴素规划与**域随机化安全裕量**
    （障碍半径膨胀 margin）。

## 3. 实测（本机 CPU，可复现，证据 cpu-proto）

| 环节 | 指标 | 结果 |
|---|---|---|
| 3DGS-lite 新视角（4 个留出视角） | 轮廓 IoU / 覆盖率 / 深度 MAE | **0.73 / 1.00 / 0.25** |
| Real-to-Sim | 平面相交障碍簇数（真值 2） | **2**；主障碍重建 r≈0.70（真值平面截圆 0.69） |
| Real-to-Sim 控制 | 重建仿真中 hybrid 成功率（8 回合） | **100%** |
| Sim-to-Real | 朴素规划成功率 / 均碰撞 | **50% / 0.50** |
| Sim-to-Real | 裕量 0.22 鲁棒规划成功率 / 均碰撞 | **100% / 0** |

结论：观测→重建→控制的 Real-to-Sim 链路在合成数据上端到端跑通；显式的
安全裕量（域随机化的最简形式）把模型失配下的碰撞从 0.50 降到 0。

## 4. 已知限制与闸门
- 3DGS-lite 无旋转协方差/EWA、静态场景、低分辨率小高斯；IoU 0.73 是 CPU
  原型水平，不与论文级 3DGS/Atlas 指标比较。
- Real-to-Sim 全局规划仅覆盖**单主障碍过门**；多障碍连续绕行需全局航点规划。
- 半径校准量在合成真值上取得，真实相机需逐传感器标定。
- 闸门：GPU 上完整 3DGS/动态表达；真实多目采集与标定；MuJoCo(-MJX) 接触
  与真机 Sim-to-Real（GPU/HPC）。
